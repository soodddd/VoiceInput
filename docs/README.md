## 当前交付边界 / Current delivery boundary

0.1.4 的代码版本已在 React、Rust/Tauri、FastAPI 和 sidecar 启动日志中统一。发布 ZIP 由构建脚本生成，并在全新临时目录中检查解压结构、`asr_backend/_internal`、SHA-256 清单和后端 `/health`。

The 0.1.4 version is synchronized across React, Rust/Tauri, FastAPI, and sidecar startup logging. The release ZIP is generated by the build script and checked in a fresh temporary directory for layout, `asr_backend/_internal`, SHA-256 manifest, and backend `/health`.

运行时仍需要 NVIDIA CUDA GPU、麦克风和约 2.7 GB 的 onedir 空间；模型缓存约 1.9 GB。自动输入是否被接受取决于目标窗口权限和控件类型。构建通过、服务健康、真实语音识别和目标窗口输入是不同的验收项目，详见 0.1.4 验证报告。

Runtime still requires an NVIDIA CUDA GPU, a microphone, and about 2.7 GB for the onedir package; the model cache is about 1.9 GB. Automatic entry depends on target-window permissions and control types. A successful build, service health, real speech recognition, and target-window input are separate acceptance gates; see the 0.1.4 validation report.

## 文档维护规则 / Documentation rules

- 发布版本文档使用独立文件，不改写历史版本事实 / keep versioned notes in separate files and do not rewrite historical facts.
- 每次发布同时更新中文和英文入口、版本清单、构建命令和验证边界 / update Chinese and English entry points, version references, build commands, and validation boundaries together.
- 任何可下载运行包都必须来自同一批次的桌面 EXE 与 sidecar，并保留 SHA-256 清单 / any runtime package must contain the desktop EXE and sidecar from the same build batch and retain its SHA-256 manifest.
